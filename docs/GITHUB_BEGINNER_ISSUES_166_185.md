## 📌 Standard Contributor Principles

1. **Single-File Bounded Scope**: Every issue modifies exactly 1 file.
2. **Accessible Execution**: Can be completed by newer open-source contributors in 5–15 minutes.
3. **Verified Verification Command**: Validated against offline `npm test` suite.
4. **Rich SEO Labels**: Includes `good first issue`, `beginner-friendly`, `beginner friendly`, `difficulty:beginner`, `difficulty:easy`, `help wanted`, `contributions-welcome`, `up-for-grabs`, `hacktoberfest`, `open-source`, `community`.
